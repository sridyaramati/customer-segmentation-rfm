📊 End-to-End RFM Customer Segmentation & Revenue Security Dashboard
An end-to-end data analytics project that processes raw e-commerce transaction data in MySQL, performs RFM (Recency, Frequency, Monetary) quintile scoring, and translates customer behavior into an executive-ready Power BI dashboard focused on Revenue Security & Churn Risk.

📌 Executive Summary
Understanding customer value goes beyond basic revenue totals. This project segment 4,335 unique customers into behavioral cohorts to answer a core business question: "Where is our revenue coming from today, and how much of it is at risk of churning?"

💡 Key Insights Uncovered
🏆 Champions Drive Growth: 34.7% ($4.51K) of total revenue is generated by top-tier Champions.

⚠️ Revenue At Risk: $3.38K (43.08% of customer revenue share) sits in at-risk or churning segments (About To Sleep, At Risk, Lost), requiring immediate re-engagement campaigns.

📈 Growth Potential: $2.89K (22.23%) belongs to Loyal and Potential Loyalists, representing prime upsell opportunities.

🛠️ Tech Stack & Skills
Database / ETL: MySQL (SQL queries, NTILE(5) window functions, CTEs, Aggregations)

Data Visualization: Power BI Desktop

Data Modeling & DAX: Dynamic calculated columns, measure-based filter contexts, variable-driven logic, conditional formatting HEX mappings

Analytics Methodology: RFM Segmentation, Executive Storytelling, Revenue Risk Analysis

🔄 Data Pipeline Architecture
[ Raw Transaction Data ] 
           │
           ▼
[ MySQL Data Processing ]
  ├── Aggregate Customer Totals (R, F, M)
  ├── Set Dynamic Anchor Date (MAX(invoice_date) + 1 day)
  ├── Apply NTILE(5) Quantiles (Scores 1 to 5)
  └── Map Scores to 8 Business Segments
           │
           ▼
[ Power BI Dashboard & DAX Layer ]
  ├── Modeled Key Metrics (Total Revenue, Revenue Share %)
  ├── Segment Classification & Revenue Health Categorization
  └── Built Interactive 5x5 RFM Matrix & Heatmap

  🚀 How to Replicate This Project
Database Setup: Run the SQL scripts in the /sql directory on your MySQL instance containing transaction history.

Load to Power BI: Open Power BI Desktop and import the processed segmentation table from MySQL.

Explore Dashboard: Open /dashboard/RFM_Customer_Segmentation.pbix to interact with the visualizations, slicers, and cross-filtering effects.
